# DeepTutor Web 移动端底部导航与右侧控制面板适配需求文档

## 1. 背景

当前 DeepTutor Web 端位于：

```text
/Users/hua/Documents/project/DeepTutor/DeepTutorSerevr/web
```

现有 Web 端以电脑端布局为主，核心布局文件为：

```text
web/app/(workspace)/layout.tsx
web/app/(utility)/layout.tsx
web/components/sidebar/SidebarShell.tsx
web/components/sidebar/WorkspaceSidebar.tsx
web/components/sidebar/UtilitySidebar.tsx
```

现有布局使用左侧 Sidebar 承载主导航、次级导航、历史会话和版本信息。移动端需要改为底部 Tab 导航，并在右上角提供设置按钮，点击后从右侧弹出覆盖式控制面板。

本需求只描述移动端适配方案，不要求修改现有代码。

## 2. 目标

### 2.1 产品目标

在手机浏览器中提供清晰、稳定、接近原生 App 的导航体验：

- 底部 Tab 固定展示 6 个主入口：主页、伙伴、智能体、写作、书籍、学习空间。
- 右上角固定展示设置按钮。
- 点击设置按钮后，右侧弹出覆盖式控制面板。
- 控制面板展示 4 个入口：记忆、知识中心、设置、版本。
- 点击控制面板中的入口后，关闭面板并进入对应页面。
- 不影响电脑端现有页面、布局、侧边栏和交互。

### 2.2 技术目标

- 只在移动端断点启用新导航，桌面端继续使用现有 `WorkspaceSidebar` / `UtilitySidebar`。
- 使用现有 Next.js App Router 路由，不新增业务路由。
- 复用现有设计变量：`--background`、`--foreground`、`--secondary`、`--accent`、`--border`、`--muted-foreground`、`--overlay`。
- 复用现有 lucide-react 图标体系。
- 尽量抽出独立移动端组件，减少对现有桌面 Sidebar 的侵入。

## 4. 设备与断点

### 4.1 适配断点

建议使用 Tailwind 的 `md` 断点作为桌面与移动分界：

```text
移动端：< 768px
桌面端：>= 768px
```

实现原则：

```tsx
<div className="md:hidden">移动端导航</div>
<div className="hidden md:flex">桌面端 Sidebar</div>
```

桌面端的现有结构不应因为移动端适配发生视觉变化。

### 4.2 目标机型

优先保证：

- iPhone SE 宽度 375px。
- iPhone 15/16 系列宽度 393px / 430px。
- 常见 Android 宽度 360px / 412px。
- 横屏时不出现导航遮挡核心操作。

## 6. 交互设计

### 6.1 底部 Tab

底部 Tab 固定在视口底部：

- 高度：`64px + safe-area-inset-bottom`。
- 背景：`var(--background)` 或 `var(--secondary)`。
- 顶部分割线：`1px solid var(--border)`。
- 当前激活 Tab 使用浅色背景块或强调色文字。
- 图标位于上方，文字位于下方。
- 每个 Tab 点击区域最小高度不低于 `48px`。
- 支持浏览器返回和前进，激活态根据 `usePathname()` 计算。

推荐样式：

```text
底部栏高度：64px
左右内边距：6px
单个 Tab：flex-1
图标尺寸：20px
文字尺寸：10px-11px
激活背景：var(--accent)
圆角：10px-12px
```

### 6.2 右上角设置按钮

设置按钮固定在移动端顶部右侧：

- 仅移动端显示。
- 位置：`top: calc(10px + env(safe-area-inset-top))`，`right: 12px`。
- 尺寸：`40px * 40px`。
- 图标：`Settings`。
- 背景：`var(--background)`，带边框和轻微阴影。
- 不遮挡页面标题和主要操作。

### 6.3 右侧覆盖控制面板

控制面板从右侧滑入：

- 遮罩覆盖全屏。
- 面板宽度：`min(76vw, 280px)`。
- 面板高度：`100dvh`。
- 进入动画：`x: 100% -> 0`。
- 离开动画：`x: 0 -> 100%`。
- 遮罩点击关闭。
- `Esc` 关闭。
- 点击面板内入口后关闭并跳转。

视觉参考用户提供的第二张图：

```text
图标在左，文字在右。
每项高度约 56px。
左边距 20px。
图标 22px。
文字 22px 左右，字重 500。
版本号使用等宽或普通数字，字号 20px。
```

### 6.4 页面内容安全区域

移动端页面主内容必须避开底部 Tab：

```css
padding-bottom: calc(72px + env(safe-area-inset-bottom));
```

如果聊天输入框已经固定在底部，应把聊天输入框上移到底部 Tab 上方，或让底部 Tab 在聊天页面隐藏。建议本期选择：

```text
主页 / Chat 页面保留底部 Tab，但聊天输入区域底部距离增加到 Tab 高度之上。
```

需要逐页验收，避免底部 Tab 遮挡发送按钮、输入框、滚动到底部内容。

## 7. 视觉设计细节

激活态文字：var(--foreground)

图标线宽：active 2，inactive 1.7

## 8. 技术方案

### 8.1 推荐新增组件

建议新增移动端专用组件，不直接改写 `SidebarShell` 的主体逻辑：

```text
web/components/mobile/MobileAppShell.tsx
web/components/mobile/MobileBottomTabs.tsx
web/components/mobile/MobileControlDrawer.tsx
web/components/mobile/mobileNav.ts
```

职责划分：

| 文件 | 职责 |
|---|---|
| `MobileAppShell.tsx` | 组合顶部设置按钮、右侧面板、底部 Tab，并包裹 children |
| `MobileBottomTabs.tsx` | 底部主导航 |
| `MobileControlDrawer.tsx` | 右侧覆盖控制面板 |
| `mobileNav.ts` | 移动端导航配置与路由映射 |

### 8.2 布局接入点

建议优先接入：

```text
web/app/(workspace)/layout.tsx
web/app/(utility)/layout.tsx
```

当前桌面结构：

```tsx
<div className="flex h-screen overflow-hidden">
  <WorkspaceSidebar />
  <main className="flex-1 overflow-hidden bg-[var(--background)]">
    <CapabilityGate>{children}</CapabilityGate>
  </main>
</div>
```

建议改造方向示例：

```tsx
<div className="flex h-screen overflow-hidden">
  <div className="hidden md:block">
    <WorkspaceSidebar />
  </div>

  <main className="hidden flex-1 overflow-hidden bg-[var(--background)] md:block">
    <CapabilityGate>{children}</CapabilityGate>
  </main>

  <div className="block h-dvh w-full overflow-hidden bg-[var(--background)] md:hidden">
    <MobileAppShell>
      <CapabilityGate>{children}</CapabilityGate>
    </MobileAppShell>
  </div>
</div>
```

注意：上面只是关键代码样本，不是本需求阶段要修改的代码。

### 8.4 底部 Tab 组件样本

```tsx
"use client";

import Link from "next/link";
import { usePathname } from "next/navigation";
import { MOBILE_PRIMARY_NAV } from "./mobileNav";

export function MobileBottomTabs() {
  const pathname = usePathname();

  return (
    <nav
      className="fixed inset-x-0 bottom-0 z-40 border-t bg-[var(--background)]/95 px-1.5 pb-[max(env(safe-area-inset-bottom),6px)] pt-1.5 backdrop-blur md:hidden"
      aria-label="移动端主导航"
    >
      <div className="grid h-14 grid-cols-6 gap-1">
        {MOBILE_PRIMARY_NAV.map((item) => {
          const active = item.match.some((prefix) => pathname.startsWith(prefix));
          return (
            <Link
              key={item.href}
              href={item.href}
              aria-current={active ? "page" : undefined}
              className={`flex min-w-0 flex-col items-center justify-center gap-0.5 rounded-[10px] text-[10.5px] leading-none transition-colors ${
                active
                  ? "bg-[var(--accent)] font-medium text-[var(--foreground)]"
                  : "text-[var(--muted-foreground)]"
              }`}
            >
              <item.icon size={20} strokeWidth={active ? 2 : 1.7} />
              <span className="max-w-full truncate">{item.label}</span>
            </Link>
          );
        })}
      </div>
    </nav>
  );
}
```

### 8.5 右侧控制面板样本

```tsx
"use client";

import Link from "next/link";
import { usePathname } from "next/navigation";
import { X } from "lucide-react";
import { MOBILE_CONTROL_NAV } from "./mobileNav";

const RELEASES_URL = "https://github.com/HKUDS/DeepTutor/releases";

interface MobileControlDrawerProps {
  open: boolean;
  onClose: () => void;
}

export function MobileControlDrawer({ open, onClose }: MobileControlDrawerProps) {
  const pathname = usePathname();
  const version = process.env.NEXT_PUBLIC_APP_VERSION || "v--";

  if (!open) return null;

  return (
    <div className="fixed inset-0 z-50 md:hidden" role="dialog" aria-modal="true">
      <button
        type="button"
        className="absolute inset-0 bg-[var(--overlay)]"
        aria-label="关闭控制面板"
        onClick={onClose}
      />

      <aside className="absolute right-0 top-0 flex h-dvh w-[min(76vw,280px)] flex-col border-l bg-[var(--secondary)] pt-[max(env(safe-area-inset-top),12px)] shadow-2xl">
        <div className="flex h-12 items-center justify-end px-4">
          <button
            type="button"
            onClick={onClose}
            className="flex h-10 w-10 items-center justify-center rounded-full text-[var(--foreground)] hover:bg-[var(--accent)]"
            aria-label="关闭"
          >
            <X size={22} />
          </button>
        </div>

        <nav className="mt-2 px-3" aria-label="移动端控制入口">
          {MOBILE_CONTROL_NAV.map((item) => {
            const active = item.match.some((prefix) => pathname.startsWith(prefix));
            return (
              <Link
                key={item.href}
                href={item.href}
                onClick={onClose}
                className={`flex h-14 items-center gap-4 rounded-xl px-4 text-[22px] font-medium ${
                  active ? "bg-[var(--accent)]" : "hover:bg-[var(--background)]/60"
                }`}
              >
                <item.icon size={24} strokeWidth={1.8} />
                <span>{item.label}</span>
              </Link>
            );
          })}
        </nav>

        <a
          href={RELEASES_URL}
          target="_blank"
          rel="noreferrer noopener"
          className="mx-3 mt-2 flex h-12 items-center rounded-xl px-4 text-[20px] font-medium tabular-nums hover:bg-[var(--background)]/60"
        >
          {version}
        </a>
      </aside>
    </div>
  );
}
```

### 8.6 MobileAppShell 样本

```tsx
"use client";

import { useState } from "react";
import { Settings } from "lucide-react";
import { MobileBottomTabs } from "./MobileBottomTabs";

export function MobileAppShell({ children }: { children: React.ReactNode }) {

      </div>

```

## 9. 不影响电脑端的实现约束

必须满足以下约束：

1. 所有移动端组件必须使用 `md:hidden` 限制显示范围。
2. 所有桌面 Sidebar 必须使用 `hidden md:block` 或 `hidden md:flex` 包裹，桌面端行为不变。
3. 不修改 `PRIMARY_NAV` 和 `SECONDARY_NAV` 的现有桌面渲染逻辑，除非只是抽取共享配置。
4. 不修改桌面端 sidebar 宽度、折叠状态、历史会话、footer、版本徽标。
5. 不修改业务页面路由。
6. 不修改接口请求、权限判断、登录态判断。
7. 移动端样式优先通过新增组件 className 实现，不在 `globals.css` 中加入大范围覆盖规则。
8. 若必须改全局 CSS，只允许新增安全区域工具类，不允许覆盖桌面选择器。

## 10. 页面级适配要求

### 10.1 主页 / Chat

重点风险：

- 底部 Tab 遮挡聊天输入框。
- 右上角设置按钮遮挡聊天标题或工具按钮。
- 消息列表滚动到底部时最后一条消息被 Tab 遮挡。

验收要求：

- 聊天输入框在移动端完整可见。
- 发送按钮完整可点击。
- 键盘弹起时输入区不被底部 Tab 永久遮挡。
- 消息列表底部至少保留 `88px` 可滚动余量。

### 10.2 伙伴

验收要求：

- 伙伴列表单列显示。
- 点击伙伴进入详情或聊天行为不变。
- 底部 Tab 不遮挡列表最后一项。

### 10.3 智能体

验收要求：

- 智能体列表、导入、连接入口在 360px 宽度下可操作。
- 卡片内容不横向溢出。
- 长名称截断或换行合理。

### 10.4 写作

验收要求：

- 编辑区、预览区在移动端可以纵向切换或上下排列。
- 底部 Tab 不遮挡主要输入区域。
- 工具栏支持横向滚动或折行。

### 10.5 书籍

验收要求：

- 书籍列表单列显示。
- 阅读页底部内容不被 Tab 遮挡。
- 章节导航在移动端可触达。

### 10.6 学习空间

验收要求：

- 仪表盘模块单列或两列自适应。
- 学习入口不被顶部设置按钮遮挡。
- 横向信息图或复杂区域支持横向滚动。

### 10.7 记忆 / 知识中心 / 设置

验收要求：

- 从右侧控制面板点击后进入对应页面。
- 页面进入后控制面板关闭。
- 当前页面在控制面板中显示激活态。

## 11. 动画与状态

### 11.1 动画参数

推荐使用 CSS transition 或 framer-motion。项目已有 `framer-motion`，可以复用。

右侧面板：

```text
duration: 0.18s - 0.24s
ease: cubic-bezier(0.22, 1, 0.36, 1)
```

遮罩：

```text
opacity: 0 -> 1
duration: 0.16s
```

底部 Tab：

```text
active state transition: 120ms
```

### 11.2 无障碍状态

- 右侧控制面板使用 `role="dialog"` 和 `aria-modal="true"`。
- 设置按钮有明确 `aria-label`。
- 底部 Tab 当前项设置 `aria-current="page"`。
- 面板打开后建议锁定背景滚动。
- 面板打开后建议焦点移动到关闭按钮或第一个导航项。
- 支持 `Esc` 关闭。

## 13. 验收标准

### 13.1 移动端验收

- 手机宽度下不显示桌面左侧 Sidebar。
- 底部固定显示 6 个 Tab。
- Tab 文案不溢出、不重叠。
- 当前页面 Tab 有清晰激活态。
- 右上角设置按钮可点击。
- 点击设置按钮后，右侧控制面板覆盖显示。
- 点击遮罩、关闭按钮或入口后，面板正确关闭。
- 记忆、知识中心、设置均可跳转。
- 版本号正确展示。
- 页面底部内容不被 Tab 遮挡。

### 13.2 桌面端验收

- 电脑端仍显示现有左侧 Sidebar。
- Sidebar 折叠/展开功能不变。
- Recents 会话列表不变。
- 底部 Tab 不出现在桌面端。
- 右上角移动端设置按钮不出现在桌面端。
- 路由、权限、登录态、主题切换不受影响。

## 15. 风险与注意事项

| 风险 | 说明 | 规避方式 |
|---|---|---|
| 聊天输入框被遮挡 | Chat 页面可能已有固定底部输入框 | 给聊天页面增加移动端底部安全距离 |
| 右上角按钮遮挡原页面按钮 | 部分页面顶部已有操作按钮 | 控制按钮尺寸固定，必要时页面顶部增加右侧 padding |
| 桌面端被误改 | 修改 layout 时可能影响原 sidebar | 使用 `md:hidden` / `hidden md:block` 明确隔离 |
| 导航配置重复 | 移动端和桌面端各自维护数组 | 后续可抽取共享 nav config，但本期不强制 |
| 权限锁定状态遗漏 | 桌面端 nav 有 capability gating | 移动端应复用 `useCapabilityAccess()`，无权限时禁用入口 |

## 16. 结论

移动端适配建议采用“新增移动端 Shell + 保留桌面 Sidebar”的方案。底部 Tab 负责高频入口，右上角控制面板负责低频入口和版本信息。实现时只在 `<768px` 下启用移动端组件，桌面端继续沿用现有 `WorkspaceSidebar`、`UtilitySidebar` 和 `SidebarShell`，从结构上避免影响电脑端页面。
